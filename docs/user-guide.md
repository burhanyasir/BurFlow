# BrightSmile AI — User Guide

Welcome to BrightSmile AI, the agency platform that deploys AI assistants for local service businesses. This guide explains how to use the platform day to day.

## What is BrightSmile AI?

BrightSmile AI is a multi-tenant platform that lets an agency (you) launch, manage, and monitor AI chat assistants for many clients. Each client gets a branded assistant that:

- Greets website visitors
- Answers common questions (hours, location, insurance, pricing)
- Books appointments
- Captures leads
- Triages emergencies

## The Console

Log in to the Agency Console at `/admin`. The navigation has:

- **Dashboard** — agency-wide KPIs and pipeline
- **Client CRM** — all your client accounts
- **Onboarding** — the checklist that takes a client to launch
- **Website Scanner** — crawl a client site to bootstrap content
- **Proposals** — sales documents
- **Invoices** — billing
- **Tenants & Branding** — per-client branding
- **Deployment** — install snippet and readiness
- **System Health** — server status

## Everyday Tasks

### Check the pipeline

Open the Dashboard to see total clients, pipeline value, monthly revenue, and how many sites are queued for scanning.

### Review a client

Open **Client CRM**, click a client, and review their status, onboarding progress, and budget. Use the workflow shortcuts to jump to scanning, proposals, invoicing, branding, or deployment.

### Answer a question about a bot

Open the client, then **Deployment** to see the live widget. You can also open the client's site and use the widget directly.

## Tips

- Use the Website Scanner before writing any content — it does the heavy lifting.
- Keep branding consistent with the client's existing site colors.
- Mark onboarding tasks complete as you finish them; the Deployment center reflects readiness automatically.
