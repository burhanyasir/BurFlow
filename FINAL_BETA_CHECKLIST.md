# Final Beta Checklist

## Customer Journey
- [ ] User can sign up and reach onboarding.
- [ ] User can submit a website and see progress feedback.
- [ ] User can generate knowledge and preview the sales agent.
- [ ] User can copy and install the widget in a few minutes.
- [ ] User can see conversations and analytics in the dashboard.

## Product Quality
- [ ] Core dashboard answers the business context question clearly.
- [ ] Widget install flow is easy to follow.
- [ ] Empty and loading states guide the user to the next action.
- [ ] Mobile and desktop layouts are acceptable for beta.

## Production Readiness
- [ ] Security and privacy basics reviewed.
- [ ] Error handling and recovery paths covered.
- [ ] Beta launch notes and support path documented.
