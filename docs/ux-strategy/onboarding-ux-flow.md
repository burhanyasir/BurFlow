# Onboarding UX Flow

## Goal
Turn curiosity into action with the fewest possible steps.

## Recommended flow
1. Visitor lands on homepage and sees one clear CTA: Scan My Website.
2. User enters website URL.
3. System quickly shows a progress state: scanning site, understanding business, preparing agent.
4. User sees a short success state with what the agent will be able to do.
5. User is offered one next step: activate widget, review insights, or book a demo.

## UX principles
- Minimize form fields.
- Make progress visible.
- Remove ambiguity from the next step.
- Show a clear payoff early.

## Why this improves conversion
A guided onboarding experience reduces friction and moves the user from interest to trust faster.
