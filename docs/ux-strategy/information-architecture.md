# Information Architecture

## Homepage hierarchy
1. Hero
2. Trust and proof
3. The core promise: website scan to AI sales agent
4. How it works
5. Competitive differentiation
6. Live widget preview
7. Pricing
8. Final CTA

## Core page structure
### Homepage
Purpose: establish value, reduce skepticism, drive action.

Primary message:
- BurFlow scans your website and creates an AI Sales Agent that understands your business.

### Pricing page
Purpose: reduce perceived risk and clarify fit.

Should include:
- Simple plan tiers
- Clear ROI framing
- Fast setup language
- Enterprise reassurance

### Signup / onboarding page
Purpose: transition from interest to action.

Should provide:
- Website URL input
- Clear progress steps
- Minimal form friction
- Immediate next-step confidence

### Docs and support pages
Purpose: answer practical questions without overpowering the core conversion path.

These should support conversion, not replace it.

## Navigation guidance
- Lead the first-time visitor to one main destination: try BurFlow.
- Keep secondary pages easy to understand and low-friction.
- Make the product feel premium through structure, pacing, and editorial discipline.
