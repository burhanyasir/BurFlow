# Mobile Review — BurFlow Experience

## Summary
Mobile is a critical channel for this product because the widget is a conversational entry point and owners will often review the site from mobile. The experience should feel especially polished and frictionless on small screens.

## Findings
### Spacing
- Content should have more generous vertical spacing on mobile
- The widget should feel less cramped and more focused

### Tap Targets
- Buttons should be easy to hit without accidental taps
- Primary CTAs should be prominently sized and spaced

### Scrolling
- The landing page should avoid awkward scroll jumps
- The widget should support smooth movement to the most recent response

### Typography
- Headings should be slightly shorter and more scannable on mobile
- Body copy should be comfortably readable without zooming

### Responsiveness
- The widget should switch cleanly into a full-height mobile layout
- The layout should preserve focus on the primary CTA and the chat entry point

### Widget Behavior
- The widget should not obscure the main action area on mobile
- The open state should feel intentional and not visually overwhelming

## Recommendations
1. Increase tap target size for main CTAs and chips
2. Simplify mobile copy and reduce sections above the fold
3. Keep the most important action visible without requiring long scrolls
4. Improve widget positioning and safe-area handling on mobile devices
5. Ensure all cards and chips stack cleanly on narrower screens
