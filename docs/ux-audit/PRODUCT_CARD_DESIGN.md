# Product Card Design — Premium Conversion UI

## Goals
Cards should make the product feel premium, tangible, and easy to evaluate. They should help visitors understand value quickly and promote the next action.

## Card Types
### Products
- product icon or visual
- short headline
- 2–3 key benefits
- optional pricing badge
- CTA: View Details / Compare / Book Demo

### Services
- service outcome headline
- timeline or deliverable highlight
- CTA: Learn More / Book a Call

### Pricing / Plans
- plan name
- monthly pricing or pricing note
- best fit summary
- CTA: Choose Plan / Book Demo

### Demo Booking
- clear headline
- small benefit statement
- CTA: Schedule Demo

### Contact Sales
- short, direct message
- CTA: Talk to Sales

### FAQ
- short answer preview
- CTA: View Answers

### Testimonials / Case Studies
- quote or result
- company name or context
- CTA: Read Case Study / See Results

## Design Principles
- Use clean spacing and strong hierarchy
- Keep the layout scannable
- Maintain consistent card rhythm
- Highlight the best next action clearly
- Use premium visual structure rather than generic list formatting
