# BurFlow UX Strategy Pack

This folder contains the research-driven product strategy documents for BurFlow.

## Central promise
BurFlow scans a website and creates an AI Sales Agent that understands the business and helps convert visitors into customers.

## Strategic principles
- Make the website feel like a premium sales platform, not a generic chatbot.
- Make website scanning the hero action and documents optional.
- Reduce cognitive load with clear next steps and visible proof.
- Build instant trust through authority, evidence, and low-friction action.
