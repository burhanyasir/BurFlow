# BrightSmile AI — Client Onboarding Guide

This guide is for agency teams onboarding a new client onto BrightSmile AI. Follow it in order; each step unlocks the next.

## The Onboarding Checklist

Every client gets a four-category checklist (visible in **Onboarding**):

1. **Setup** — collect contact info, schedule kickoff, create tenant
2. **Branding** — subdomain, colors, greeting
3. **Content** — scan site, review services/FAQs, add team
4. **Deployment** — staging, testing, approval, production

## Phase 1 — Setup (Day 0)

- [ ] Create the client in **Client CRM**
- [ ] Collect business name, website, email, phone
- [ ] Schedule a 20-minute kickoff call
- [ ] Create the tenant (auto-created on client creation)

**Kickoff call agenda**: confirm goals, primary services, branding preferences, and go-live date.

## Phase 2 — Branding (Day 1)

- [ ] Set subdomain (e.g., `maplegrove`)
- [ ] Upload or link logo
- [ ] Choose primary/secondary colors from the client's site
- [ ] Write a friendly greeting

## Phase 3 — Content (Day 1–2)

- [ ] Run the **Website Scanner** on the client's homepage
- [ ] Review extracted services — add or remove as needed
- [ ] Review FAQs — confirm answers are accurate
- [ ] Add team member names/titles
- [ ] Click **Apply to Chatbot Config**

If the scanner misses something, you can edit the config manually in the console (coming via the config editor) or re-scan after the client updates their site.

## Phase 4 — Deployment (Day 2–3)

- [ ] Generate a **Proposal** and send it
- [ ] On acceptance, create the first **Invoice**
- [ ] Paste the install snippet into a staging page
- [ ] Test: book an appointment, ask an FAQ, trigger an emergency response
- [ ] Get client approval
- [ ] Deploy to production
- [ ] Mark deployment tasks complete

## Handoff

Send the client a short summary: what the bot can do, how to edit content (via you), and who to contact for support.

## Time to Launch

With the Website Scanner, most clients go live in **under 15 minutes** of active work — the rest is scheduling and approvals.
