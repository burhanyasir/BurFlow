# Competitive Gap Analysis

## Competitors Reviewed
- SiteGPT
- Chatbase
- Intercom Fin
- Zendesk AI
- CustomGPT

## Where BurFlow is stronger
- Stronger website-specific grounding because it can use the scanned site and generated knowledge base directly.
- More sales-oriented presentation than a generic support bot.
- Clearer onboarding path for non-technical users.

## Where BurFlow is weaker
- Less mature than established support suites in analytics depth and enterprise admin workflows.
- Widget polish and onboarding guidance still need to feel more premium and frictionless.
- Some competitor experiences have more refined admin and analytics surfaces.

## Features required before beta
- Clear business-profile dashboard summary.
- Smooth widget install and verification path.
- Cleaner analytics and conversation visibility for early customers.

## Features that can wait until after launch
- Deep multi-workspace admin operations.
- Advanced predictive lead scoring.
- Large-scale enterprise security and compliance features beyond the core beta scope.
